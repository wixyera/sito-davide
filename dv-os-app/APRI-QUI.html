Il tuo universo.
Pronto a ripartire.

Ingresso 3D, animazioni e recupero password via email. Questa pagina ti accompagna nella configurazione.

La vecchia Edge Function non serve più.

Non incollare il codice password-reset in Supabase. Questa versione usa direttamente il servizio di autenticazione via email.

01 / Aggiorna il sito

Carica i file nel repository GitHub collegato a Cloudflare, mantenendo dv-os-app come cartella del progetto. Se il contenuto è nella radice del repository, lascia vuota la Root directory.

La cartella functions deve stare accanto a package.json. Pubblica tramite Git o Wrangler per includere anche le API.

02 / Attiva le email

  1. In Supabase Authentication abilita Confirm email per il provider Email.
  2. In URL Configuration inserisci l’indirizzo reale della home in Site URL e Redirect URLs, con / finale.
  3. Configura il tuo SMTP, oppure conserva quello già funzionante.
  4. In Email Templates copia il codice HTML dei tre file elencati sotto.
  5. Abilita anche la notifica di sicurezza Password changed.
Template SupabaseFile da aprire nell’editor di testo
Confirm sign upemail-templates/conferma-account.html
Reset passwordemail-templates/recupero-password.html
Password changedemail-templates/password-modificata.html

Nei primi due conserva {{ .ConfirmationURL }}: diventerà il link personale per l’utente. Non sostituirlo con l’URL generico del sito.

Guida email completaTutte le istruzioni

03 / Prova il nuovo flusso

Registra un account di prova → apri l’email di conferma → esci → premi “Password dimenticata?” → richiedi il link → imposta la nuova password → accedi di nuovo.

Dopo averlo verificato, puoi eliminare la vecchia funzione password-reset dal pannello Edge Functions, se l’avevi pubblicata. I vecchi account non vanno ricreati.

04 / Esplora il tuo spazio

La scultura reagisce al puntatore; i titoli e le schede entrano progressivamente; le sezioni cambiano con una transizione. Il pulsante pausa ferma il movimento. Se il browser non supporta WebGL, l’ingresso conserva l’immagine alternativa.

Per aprire l’app in locale usa npm run dev e visita http://127.0.0.1:4173. Aprire direttamente index.html non avvia i servizi.
